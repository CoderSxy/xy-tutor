# 年级科目选择历史卡片 · 2026-11-09

教材选择页第一张卡固定为“选择年级和科目”，打开既有教材版本/年级/科目/册次表单；后续卡片为当前学生的历史选择，点击快捷进入对应学习空间。保持A工作台配色和组件风格。

选择历史存入PostgreSQL新增student_selections表；每学生的年级+科目有唯一约束，同组重复选择更新最近教材版本/册次与时间，最近使用排在前面。后端从教材修订推导年级/科目，不信任客户端自行提交的分类。服务端沿用StudentScope权限隔离。

浏览器已有的最后一次有效教材选择，在服务器历史为空时自动补入历史；不会声称能恢复此前未被记录的所有选择。清除本地存储后仍可从服务器取得历史。教材停用后卡片保留并要求重新选择；没有已发布教材时历史仍显示。已有学习任务继续绑定原教材修订，不受切换选择影响。

保存失败保留表单输入并提示；切换学生后不把上个学生的异步响应应用到当前界面。弱网下历史GET晚返回覆盖刚完成POST选择的问题已先复现，再加入请求版本保护并验证通过。
