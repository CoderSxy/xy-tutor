# 初版验收记录 · 2026-11-08

本次在 macOS、Node 22.22、PostgreSQL 14、已安装 Google Chrome 上验收。生产目标为 Ubuntu 24.04 / PostgreSQL 17；两个环境的结果分开记录。

## 已验证

- 单元测试18项、真实PostgreSQL集成43项、浏览器15项全部通过；typecheck、lint、build通过。
- 完整浏览器链路使用真实Fastify、PG、pi Agent和PDF解析：管理员上传/封存/解析/发布教材 → 学生选择教材 → 每日5练 → 首次答错待订正 → 原题答对待巩固 → 完成5题/保存/回看 → 学生上传试卷并仅确认所选题 → 管理员无权访问 → 学生授权可访问 → 撤销后不可访问。
- 仅外部模型与OSS使用测试适配器；不会以此宣称真实供应商、图片理解或教学质量通过。
- 数据库集成检查独立变式、跨日新变式达到掌握，之后更正证据撤销掌握，历史事件仍保留。时间只在测试库构造，不开放生产跳过时间接口。
- 双设备版本冲突、重复提交、执行中断/重启、事件游标回放、旧教材停用后继续旧任务、权限隔离、资料部分确认、题目/消息更正失效、核验失败和资源限额有回归覆盖。
- 网络响应丢失后重试复用幂等键；刷新会恢复教材选择并查询服务端最近执行，不依赖浏览器刚好收到runId。
- 未完成每日5练时保存为暂停；后端拒绝不足5题的完成请求。
- 360/390/768/1024/1280/1440px检查首页、学习页、资料、设置、历史、错题页面无整页横向溢出。首页与学习页截图保存在screenshots/，为明确的合成测试数据。
- 已目视检查移动、Pad及PC代表截图；统一使用A方向、森林绿与浅薄荷底色。Impeccable静态检测返回空问题列表。

## 验收边界

- 真实LLM_MODEL/API Key未提供；供应商文本流式、工具调用、图片输入、取消/超时及教学质量仍需真实冒烟。
- OSS/OCR尚未开通；真实CORS、私有下载、扫描照片识别、教材质量与真实试卷拆题仍待验收。当前提供配置说明和明确未启用提示。
- 自动化为Chrome视口模拟；iOS Safari、Android Chrome、Pad旋转、相机和软键盘未做真机验收。各后台编辑页面已有功能用例，但未逐页覆盖所有屏宽的视觉截图。
- Docker daemon未运行；未执行PG17镜像构建或容器限额压力测试，也未连接/部署ECS。2核2GiB容量是部署预算，不能由本机测试推定真实上限。
- 本机剩余磁盘不足10%，资源保护会暂停后台解析；浏览器业务测试注入健康资源条件，真实保护由独立用例验证。
