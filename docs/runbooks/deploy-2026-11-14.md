## 2. 展开新版本

```bash

ls "$RELEASE"; ls "$RELEASE/backend/dist/server/packages/db/src/migrate.js"
```

## 3. 停服务（迁移窗口）

```bash
sudo systemctl stop xy-tutor
```

线上水位停在 `0022`，本次要执行 `0023`–`0029` 共 7 个迁移：全部是 `CREATE TABLE`、外键、
索引与 `ADD COLUMN … DEFAULT`，没有 `DROP TABLE` / `UPDATE` / `DELETE`；唯一的 `DROP CONSTRAINT`
是 `0024` 对 `knowledge_items_status_check` 的立即重建。`0029` 的两条 `CREATE INDEX` 会短暂
阻塞写，目标表线上为空。旧版本代码与新增表向后兼容，但 `0025` 之后的新列只有新代码会读。

## 4. 迁移

```bash
sudo -u xy-tutor /usr/local/bin/node \
  --env-file=/opt/xy-tutor/.env \
  "$RELEASE/backend/dist/server/packages/db/src/migrate.js"
```

失败即停：不要切换到新版本，恢复旧版本并排查。
